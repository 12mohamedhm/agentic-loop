# Invariants

Each line is law; each carries its provenance. A change to this file is a
constitutional amendment: it requires a postmortem naming the failure that
demanded it.

1. The hub's context is an index, never a payload. (Bavelas/Leavitt: wheel
   networks win until the hub saturates.)
2. Seats and phases communicate only through schema'd artifacts. A missing
   fact is a schema amendment, never a side channel. (I-PASS: structure
   prevents omission.)
3. Regenerate, never transcribe. Machine state is re-collected each hop;
   every count, hash, and superlative is recomputed at the seat that writes
   it. (Serial-reproduction drift; the K-1 law.)
4. Workers run fresh-context, decorrelated by role and framing. Consensus
   among clones is weak evidence; sample unanimous passes. (Hidden-profile:
   unique information drives quality; same-family errors correlate.)
5. Delegate intent: purpose, method, end-state, exact write-set. The how
   belongs to the worker; a gap returns as a deviation artifact, never as
   improvisation. (Mission command; the write-set law.)
6. Gates are executable and completeness-based. Length floors are banned;
   field completeness is the bar. A gate may be modified only through its
   own contract, in a separate changeset from anything it gates.
7. Interrogation is separable from answering. Clones may grill; only the
   human or their ledger holds intent. An INTENT question the ledger cannot
   answer escalates — when in doubt, type as INTENT. (ACH negative result:
   topology debiases, instruction does not.)
8. Evidence is banked. A finding is CITABLE only when raw source bytes are
   resident, hashed, and cited by span; summarizer or snippet material is
   NOMINATED and never load-bearing. Fetch to disk, then extract locally.
9. Design consumes a sources-of-record annex: every external dependency
   pinned to banked authoritative docs before authorship; upstreams
   re-checked for drift at implementation entry. Disk and banked bytes
   outrank memory and handoff sentences.
10. Every gate is a handoff; the chain is the mission's commit log. Seam
    proactively near 60% context, at a lawful boundary.
11. Fixes ship through the pipeline: a fix is a contract that passes
    Implementation and Validation like any change.
12. Kill the class, not the instance: every postmortem factor lands in a
    typed home — schema field, regime data, gate code, or discipline prose.
    A rule that cannot name its home is project law and stays in the project.
13. The human surface is policy: reversibility tiers (autopilot / gate /
    hard-deny) plus a per-phase mode vector. Escalations-per-mission is the
    measured autonomy curve.
14. Scripts prepare; models decide. The composer substitutes and assembles;
    judgment stays with model seats and the human.
