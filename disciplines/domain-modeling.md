# Discipline: Domain modeling

Build the project's shared language in CONTEXT.md; the codebook that makes
every later artifact denser. Runs inside grilling sessions and design, and
whenever a concept needs three sentences twice.

1. Name the concept with an industry term when one exists; coin only when
   nothing pretrained fits, and define it at first use.
2. One entry per term: definition, boundaries, the mistake it prevents.
   Stress-test with an edge case before it enters the glossary.
3. Contracts, briefs, verdicts, and handoffs use glossary terms bare —
   the glossary is the single home for their meaning.
4. A term that changes meaning gets a superseding entry with a link, and a
   sweep of live artifacts that used the old sense.
