# Discipline: Research

Answer the mission's open questions with independent, saturation-terminated,
banked evidence. The hub frames and synthesizes; workers search. Regime:
scope-question answerer = {{ANSWERER}}, worker ceiling = {{BUDGET_WORKERS}}.

## Steps

1. Pre-register the protocol (schemas/research-protocol.md) before any
   search: questions, inclusion/exclusion criteria, disjoint worker
   mandates. Scope disputes go to {{ANSWERER}}.
2. Fan out — one worker per mandate (templates/mandate-researcher.md),
   scaled to breadth within {{BUDGET_WORKERS}}. Each mandate carries the
   saturation stopping rule and the citability lanes: discovery tools
   nominate; only raw bytes banked to disk (fetch-to-disk, extract locally,
   hash recorded) make a finding CITABLE.
3. Synthesize from returned summaries; open full briefs only on conflict or
   flagged relevance. Hunt findings that appear in exactly one brief —
   unique information is where synthesis quality lives. Load-bearing claims
   cite CITABLE findings only.
4. Mark every protocol question ANSWERED or UNANSWERABLE-escalate; gaps get
   one targeted second wave.

## Done when

Every question marked; synthesis written with per-question answer,
confidence, dissent, and gaps; novel-findings-per-search recorded.
